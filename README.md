# 🎂 Age Calculator

A simple and clean **Age Calculator** web app built using **HTML, CSS, and JavaScript**. This was made as part of my web development internship at **CodeAlpha**.

---

## 📸 Preview

![Age Calculator Preview](preview.png)

> *Enter your date of birth and instantly get your exact age along with fun stats!*

---

## ✨ Features

- 📅 Input date of birth (Day / Month / Year)
- 🔢 Shows exact age in **Years, Months, and Days**
- 📊 Bonus stats:
  - Total days lived
  - Total weeks lived
  - Total hours lived
  - Next birthday countdown
  - Day of the week you were born
  - Your zodiac sign ♈
- 📈 Life progress bar (based on 80 yr average)
- ✅ Full input validation with helpful error messages
- ⌨️ Keyboard friendly — press Enter to calculate
- 📱 Fully responsive on mobile

---

## 🛠️ Tech Stack

| Technology | Usage |

| JavaScript (ES6+) | Age calculation logic using `Date` object |

**Key Concepts used:**


2. **Open the project folder**
   ```bash

   ```

3. **Open `index.html` in your browser**
   ```bash
   # Just double-click index.html
   # OR use Live Server in VS Code
   ```
